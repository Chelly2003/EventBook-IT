📌 Overview

EventBook-IT is a web-based event management and ticketing system designed for small and medium event organizers in Kenya. It replaces manual booking methods (WhatsApp, spreadsheets, calls) with a simple, automated, and secure digital platform.

The system supports event creation, ticket sales, secure M-PESA STK Push payments, PDF ticket generation, real-time ticket availability, KRA PIN verification, email notifications, and organizer analytics.

🎯 Aim

To design and develop an affordable, user-friendly, and secure event booking system that automates event creation, ticket management, payments, and ticket generation for Kenyan event organizers.

⭐ Key Features
👤 Users & Organizers
User registration & login
Organizer KRA PIN verification
Profile management
Password reset using Gmail API
🎫 Event Management
Create, update, edit, and delete events
Upload event banner
ticket generation
Real-time ticket availability
Automatic “Sold Out” indicator
💰 Payment Integration
M-PESA STK Push via Daraja 3.0
Sandbox
Automatic callback validation
Secure payment confirmation
No storage of sensitive payment data
🎟️ Ticketing
PDF ticket generation
Unique reference number
QR code for verification
📊 Organizer Dashboard
Ticket sales analytics
Revenue reports
Lead-source analysis (WhatsApp, Instagram, Website, etc.)
🛠️ Tech Stack
Backend: Laravel 10
Frontend: HTML, CSS, Bootstrap, JavaScript
Database: PostgreSQL
Payment API: M-PESA Daraja 3.0
Verification API: GavaConnect
Email API: Gmail API
SMS API: SMS Sales
🔐 Security Features
Password hashing (bcrypt)
CSRF token protection
Input sanitization & validation
HTTPS support
Role-based access control
Secure API keys (stored in .env only)
No sensitive payment data stored
Strict separation of environment secrets
